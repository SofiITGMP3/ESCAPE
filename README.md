# ESCAPE

## O hře

ESCAPE je textová hra v Pythonu. Hráč se snaží uniknout ze strašidelného domu: odemyká dveře, vybírá si předměty a musí se ubránit upírovi.

## Spuštění

Otevři notebook `IT hra ESCAPE!.ipynb` v Jupyter Notebooku a spusť herní buňku pomocí **Shift+Enter**. Na úvodní otázku zadej `ano`.

## Ovládání

- Zadej `a` pro prohledání pokoje nebo `b` pro zadání kódu.
- Kód k otevření dveří je `1200`.
- Vyber tři předměty z nabídky a zadej, který chceš použít proti upírovi. Pomůže česnek.
- Na otázky odpovídej zadáním textu do vstupního pole.
